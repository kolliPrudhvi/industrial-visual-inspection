# Industrial Visual Inspection

Cross-benchmark anomaly detection system for industrial visual inspection.

## Goal

Build and compare three generations of industrial anomaly detection methods:

1. Autoencoder baseline
2. PaDiM
3. PatchCore

Benchmarks:
- MVTec AD
- VisA
- Custom self-captured dataset

Deployment:
- ONNX Runtime
- FastAPI
- Streamlit demo
